# あたらしい だいぼうけん（あたらしい 横スクロールゲームの どだい）

ルートの `index.html`（「にねんせいの だいぼうけん」）を **そのままコピーした もの** です。
ここを いじって、あたらしい 横スクロールゲームを つくります。

- `new-game/index.html` … コピーした 1ファイル。ブラウザで ひらけば すぐ うごきます。
- もとの ゲーム（ルートの `index.html`）は さわっていません。

コピー元との ちがいは タイトル文字だけです（`にねんせいの だいぼうけん` → `あたらしい だいぼうけん`）。

## つくりかえる ときの めやす

| やりたいこと | さわる ところ |
| --- | --- |
| ステージの かたち | `STAGE_DEFS`（`MAIN_*` / `S2_*` の配列） |
| おうちの 中 | `ROOMS` と `ROOM_LINKS` |
| すがた（大きさ・速さ・ジャンプ） | `FORMS` |
| 主人公の 見た目 | `drawGirl` / `drawBoy` |
| タイトル・説明の 文章 | `<h1>` まわりと `panel(...)` |

くわしい しくみは ルートの `README.md` を みてください。

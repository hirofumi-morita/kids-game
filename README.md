# にねんせいの だいぼうけん

かさを持った小学2年生の女の子が、通学路を進んで学校の校門を目指す、横スクロールのジャンプアクションゲームです。

HTML 1ファイルだけで動きます。`index.html` をブラウザで開けばすぐ遊べます（ビルド不要・外部ライブラリなし）。

## あそびかた

| そうさ | キー | タッチ |
| --- | --- | --- |
| うごく | `←` `→` / `A` `D` | 画面下の ◀ ▶ |
| ジャンプ | `スペース` / `↑` / `W`（長押しで高く） | ジャンプ |
| かさを ふる | `K` / `Shift` / `X` / `Z` / `↓` / `Enter` | かさ |
| ふわふわ おちる | 落下中に `スペース` 長押し | ジャンプを押したまま |
| かさで とぶ | 空中で `スペース` を連打 | ジャンプを連打 |
| やりなおし | `R` | － |
| おとの オン／オフ | `M` | 「おと」ボタン |

- カラスとハチは、**かさをふる**か**頭から踏む**と倒せます。
- ★（ハナマル）を集めるとスコアになります。はてなブロックは下から頭で突き上げると★が出ます。
- ハートは5つ。穴に落ちるか敵に当たると1つ減り、途中のピンクの旗（チェックポイント）から再開します。
- 校門にたどり着くとクリアです。

## しくみ

- Canvas 2D + 素の JavaScript。描画はすべてコードで図形を描いています（画像ファイルなし）。
- 物理は 60Hz 固定ステップ。タイルグリッドに対して X軸・Y軸を別々に解決する AABB 判定です。
- ステージは `GROUND_SEGS` / `BLOCKS` / `QBLOCKS` / `COIN_SPOTS` / `CROW_SPOTS` / `BEE_SPOTS` の
  配列で定義しています。ここを書き換えるとステージを作り変えられます。
- 文字は Google Fonts（M PLUS Rounded 1c / Mochiy Pop One）を読み込みます。
  オフラインでもフォールバックのゴシック体で動きます。

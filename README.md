# にねんせいの だいぼうけん

かさを持った小学2年生の女の子が、ネコやタヌキに変身しながら通学路を進み、
おうちの中も探検して学校の校門を目指す、横スクロールのジャンプアクションゲームです。

HTML 1ファイルだけで動きます。`index.html` をブラウザで開けばすぐ遊べます（ビルド不要・外部ライブラリなし）。

## そうさ

| そうさ | キー | タッチ |
| --- | --- | --- |
| うごく | `←` `→` / `A` `D` | ◀ ▶ |
| ジャンプ | `スペース` / `↑` / `W`（長押しで高く） | ジャンプ |
| こうげき | `K` / `J` / `X` / `Z` / `Shift` | こうげき |
| しらべる・ドアにはいる | `E` / `Enter` / `↓` | しらべる |
| へんしん | `C`（順番に）／`1` `2` `3`（直接） | へんしん |
| やりなおし | `R` | － |
| おとの オン／オフ | `M` | 「おと」ボタン |

## 3つの すがた

| すがた | とくちょう | とくべつな ちから |
| --- | --- | --- |
| おんなのこ | ふつうの うごき | かさを ふって こうげき。落下中にジャンプ長押しで**ふわふわ落下**、連打で**かさで飛ぶ** |
| ネコ | はやく はしれる・小さい | **2かいジャンプ**。ひっかき攻撃。1マスしかない**ネコ専用の穴**を通れる |
| タヌキ | おそいけど つよい | 地上で**たいあたり**、空中で**ヒップドロップ**。どちらも**レンガを壊せる** |

すがたを変えると当たり判定の大きさも変わります。せまい場所で大きい姿になろうとすると
「ここでは むり！」と出て変身できません。

## あそびかた

- ★（ハナマル）を集めるとスコアになります。はてなブロックは下から頭で突き上げると★が出ます。
- カラスとハチは、こうげきするか、頭から踏むと倒せます。
- 通学路には**入れるおうちが3軒**あります。ドアの前で `E`。
  中の テーブル・ほんだな・たんす・ベッド・たからばこ を `E` で調べると★がもらえます（全部で15か所）。
- かくし部屋が2つあります。
  - **みどりの おうち** … 奥の壁にネコ専用の穴。ネコに変身して通ると「やねうら」へ。
  - **きいろい おうち** … レンガの壁。タヌキに変身して壊すと「ちか」へ。
- ハートは5つ。穴に落ちるか敵に当たると1つ減り、途中のピンクの旗（チェックポイント）から再開します。
- 校門にたどり着くとクリアです。

## しくみ

- Canvas 2D + 素の JavaScript。絵はすべてコードで図形を描いています（画像ファイルなし）。
- 物理は 60Hz 固定ステップ。タイルグリッドに対して X軸・Y軸を別々に解決する AABB 判定です。
- タイルの種類：地面 / 足場 / はてなブロック / レンガ（タヌキだけが壊せる） / 室内の壁 / 室内の床。
- ステージは「エリア」の集まりです。
  - そと（`MAIN_*` の配列）… 地面・足場・コイン・敵・おうちのドアを配列で定義。
  - 中（`ROOMS` の配列）… 部屋ごとに 足場・レンガ・コイン・家具・ドアを座標で定義。
  `ROOM_LINKS` がどのドアがどの部屋につながるかを持っています。
- すがたの性能は `FORMS`（大きさ・速さ・ジャンプ力・重力）にまとまっています。
- 文字は Google Fonts（M PLUS Rounded 1c / Mochiy Pop One）。オフラインでも代替フォントで動きます。
